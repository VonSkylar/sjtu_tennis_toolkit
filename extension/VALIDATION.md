## 验证边界

- **没有使用用户原有浏览器资料、Cookie、密码或登录会话，没有向学校提交真实预约或支付。**
- 真实网站检查仅覆盖未登录页面的加载与识别；登录完成后的空场读取、日期切换、场地选中和最终创建订单，需要用真实账号继续验收。
- 浏览器自动化使用 Chromium 加载完整插件。用户截图已确认 Windows Chrome 侧边栏能打开，并报告了 1.0.0 登录后东区回首页的问题；1.0.1 的修复已通过上述夹具验证，仍需重新加载后在真实账号中确认。Edge 及 Mac 的原生运行尚未单独验收。
- 系统通知 API 与音频播放调用成功，不代表已核验每台设备的系统通知权限、扬声器或音量。
- 不将页面夹具的成功结果解释为学校平台的实际抢场成功率，也不承诺设备休眠或浏览器调度延迟时准点执行。

## 建议的首次验收顺序

1. 在扩展管理页加载已解压的插件，点击图标打开侧边栏。
2. 先关闭“唯一空场自动下单”，开始监控并正常登录学校；核对场馆、日期及识别出的空场。
3. 检查刷新后恢复、关闭侧边栏继续运行和停止任务。
4. 确认识别正确后，按实际需求开启自动下单或设置定时抢场；最终订单以学校页面和订单列表为准。
