# 网球预约助手 · 浏览器插件

在 Windows 或 Mac 的 **Chrome / Microsoft Edge 120 及以上版本**中使用。安装后直接在当前浏览器运行，不需要 Python、Playwright、本地服务或服务器。首版不支持手机和 Safari。

## 安装（第一次约几步操作）

1. 把 `sjtu-tennis-extension-1.0.2.zip` 解压到一个长期保留的文件夹。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”，选择**里面有 `manifest.json` 的文件夹**。
4. 在浏览器工具栏的扩展菜单中找到“网球预约助手”，固定图标，点击打开侧边栏。

也可以直接加载源码仓库的 `extension` 文件夹。不要删除或移动已经加载的文件夹；更新时替换该目录内容，再到扩展管理页点击“重新加载”。扩展更新后需要重新开始任务。

Chrome 商店版按[私有发布说明](CHROME_WEB_STORE.md)提交。审核通过后，白名单内的 Google 账号可通过商店链接安装，之后由 Chrome 自动更新。商店版和开发者模式版本各有自己的本地设置；切换时请先停止并停用旧版，再在商店版重新设置。

### 从 1.0.0 更新到 1.0.1

修复登录后东区停在首页的问题：按预约路由与场馆 ID 判断页面，登录后、每轮监控前及路由变化时重新校验，不再把首页推荐区的场馆名称当作预约页。

先停止任务，在扩展管理页重新加载插件，然后刷新两个学校标签页，再开始监控。使用源码目录加载时不必重新安装，已保存的配置会保留。网页刷新与后台恢复仍保留当前任务的原截止时间，订单结果页不会被强制跳回预约页。

## 开始使用

### 空场监控

选择场馆、日期、监控时段和检查间隔，再点击“开始监控”。如预约页要求登录，正常完成学校 jAccount 登录即可，插件随后自动继续。

- 默认选择两个场馆，监控 17:00–22:00，间隔 20 秒，最小 10 秒。
- 胡晓明室内场为 6、7 号；室外为 1–5、8 号。东区始终检查全部场地。
- 日期支持 `2026-11-01`、`2026-11-01,2026-11-03`、`2026-11-01~2026-11-07`，一次最多 14 天。
- 沿用旧版的轮询：每轮各场馆检查一个日期，之后轮换日期。**默认开启“唯一空场自动下单”**；本轮汇总恰好一个候选时自动提交，多个候选只提醒。只想接收提醒时，开始前取消该选项。
- 运行中可修改监控条件，有效设置会自动保存并立即生效；正在处理订单时暂停修改。
- 自动下单成功或结果不明确后，继续监控、停止后续自动提交。明确失败的同一场次至少等待 60 秒再尝试。

### 定时抢场

选择“定时抢场”，设置场馆、场地范围、优先场地、开始时间和按顺序排列的时段，然后提前点击“开始抢场”并完成登录。

- 默认胡晓明室内场、优先 6 号、12:00:00 开始。
- 默认依次尝试 19–20、20–21、21–22、18–19，可增删为 1–7 个不重复的一小时时段。
- 每个时段先尝试优先场地，再尝试范围内其余场地；成功一次即结束。
- 目标日期始终是开始任务当天的七天后；放场后一分钟结束。所有日期及时间统一使用**北京时间**。
- 运行中锁定抢场配置；更改前先停止。

### 提醒和人工操作

发现空场时显示系统通知并循环播放提示音。“停止报警”仅关闭提醒，“停止任务”会停止后续操作。结束或停止后保留学校页面供核对。

出现验证码时，在学校页面手动完成，再点击侧边栏的“检查并继续”。插件不会代填登录密码或处理验证码，也不会自动支付订单。提交结果不明确时先检查学校订单，不要直接重新开启自动下单。

## 运行条件

- 关闭侧边栏后任务继续，但**浏览器、预约标签页和设备需要保持运行**。关闭任务标签页会停止任务。
- 网页刷新、扩展后台回收后，任务按原截止时间恢复；浏览器退出、扩展重新加载或更新后，不自动重新开始任务。
- 设备休眠时不执行。恢复时如果已过抢场窗口，不会补抢；浏览器回收、系统调度及学校响应都可能造成延迟。
- 请求过于频繁时至少等待一秒再刷新；再次出现则再次等待。每日额度耗尽后停止，并记录到次日 00:10 的冷却时间。
- 插件与旧 Python 工具使用不同浏览器会话，不会搬运旧版 `browser_profile/`。在安装插件的浏览器内正常登录学校即可。
- 请勿同时运行旧版与插件预约同一账号，以免两套程序争用场次。插件内部一次只允许一种模式。

## 数据和权限

设置和日限流记录仅保存在当前浏览器的本地扩展存储；运行状态保存在本次浏览器会话中。插件不读取或导出 Cookie，不存储密码，不上传日志或账号信息。

网站权限仅为 `https://sports.sjtu.edu.cn/*`。其他权限分别用于本地配置、任务恢复、侧边栏、通知与提示音。全部执行代码随安装包提供。

完整说明见[隐私政策](PRIVACY.md)。

## 验证范围

开发测试使用独立临时 Chromium 配置和学校页面夹具，不使用用户浏览器资料，也不向学校提交真实订单。覆盖规则、真实扩展消息传递、选中与提交、刷新恢复、后台重启、关闭界面继续运行及不明确结果保护。

Windows 上的自动化结果和截图位于仓库的 `build/extension-validation/`，详细记录见 [VALIDATION.md](VALIDATION.md)。**Mac 原生 Chrome / Edge 安装、真实账号登录后的页面操作与最终订单创建仍需实际验收**；不能把夹具测试视为真实抢场成功率验证。首次使用建议先关闭自动下单验证监控识别，再按需要开启。

## 开发者验证（用户安装时不需要）

在仓库根目录运行：

```text
node --test extension/tests/rules.test.js extension/tests/controller.test.js extension/tests/package.test.js
python -X utf8 extension/tests/browser_smoke.py
python -m unittest discover -s tests
python -X utf8 extension/tools/package.py
python -X utf8 extension/tools/package.py --store
```

`tools/sync_probes.py` 将旧版共享 JavaScript 探针转成插件内的静态可执行函数；仅在维护探针时运行。打包脚本不包含开发工具、测试或 Python 文件。`--store` 生成商店专用 ZIP，上传时无需解压。
